# Как внести свой вклад в ClientFlow 

Спасибо за интерес к проекту ClientFlow Open Source! 

 Мы приветствуем любые вклады: исправление багов, улучшение документации, добавление новых интеграций и функций.

##  Как начать
1. Создайте **Fork** этого репозитория.
2. Клонируйте свой форк на локальный ПК.
3. Создайте новую ветку: `git checkout -b feature/awesome-feature`
4. Внесите изменения и сделайте коммит: `git commit -m 'feat: add awesome feature'`
5. Отправьте изменения в свой форк: `git push origin feature/awesome-feature`
6. Откройте **Pull Request** в основной репозиторий.

##  Сообщить об ошибке
Если вы нашли баг или у вас есть идея для новой фичи, создайте [Issue] с детальным описанием.
