#  ClientFlow Open Source

Self-Hosted Client Onboarding Platform for Digital Agencies, Software Houses & Consultants.

##  Quick Start (Docker)

```bash
# 1. Clone repo
git clone https://github.com/mars74da4p/b2bsaas
cd b2bsaas

# 2. Run with Docker Compose
docker-compose up -d
```

Access the Dashboard at `http://localhost:3000`

##  Key Features
- **Kanban Onboarding Pipelines:** Easily track client readiness.
- **Client Portal Simulator:** Live view of task progression.
- **Self-Hosted First:** Full ownership of your customer data.
